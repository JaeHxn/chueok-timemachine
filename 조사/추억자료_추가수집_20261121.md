## 서울기록원: 회상용 사진 컬렉션

## 추가 데이터 확보 경로

1. **국가기록원 나라기록물 검색서비스**: 사진·필름, 녹음·동영상 등 형태별 검색. 공공데이터포털에서 인증키 신청이 필요하고 공식 안내상 일 1,000건 미만. 원본 사용 권리는 기록별 확인. https://www.archives.go.kr/next/newsearch/openAPI01.do
2. **한국영상자료원 영화정보**: 기본정보 파일 다운로드, 상세정보 Open API. API는 KMDb 온라인 민원으로 신청한다. 출처: 한국영상자료원 공공데이터 FAQ https://www.koreafilm.or.kr/service/faq?type=08 (2026-11-21 조회). 영화 포스터의 별도 권리는 확인 필요.
3. **대한민국역사박물관 근현대사 아카이브 목록정보**: XML 파일 데이터. 공공데이터포털 표시상 공공누리 제4유형(출처표시·비상업·변경금지)이므로 상업 이용이나 변형에는 별도 권리 확인이 필요하다. https://www.data.go.kr/data/15083296/fileData.do

싸이월드의 일촌·파도타기와 도토리는 2004년 아이뉴스24의 당시 인터뷰를 근거로 2004년 카드 2개에 반영했다: https://www.inews24.com/view/127621. 도토리 등 미니홈피 문화는 YTN의 회고에서도 확인된다: https://www.ytn.co.kr/_ln/0106_202006221222249992. 1990년대 후반~2000년대 자료는 더 필요하며 개인 게시물·음원·방송 화면은 별도 권리 확인이 필요하다. API 키 발급과 원본 대량 다운로드는 하지 않았다.

## 애니메이션 점검

- `.ring`에 누락됐던 공전을 연결하고, 달의 글자는 반대로 회전하도록 했다. 포인터와 키보드 포커스가 궤도 위에 있으면 공전이 일시 정지한다.
- `설계/화면명세.md`에 제안된 3D 은하, 비행·착륙 및 위성 공전은 현재 `web` 앱에서 구현된 상태가 아니다. 기존 효과는 화면 등장·시트 등 CSS 애니메이션 위주다.
- OS의 동작 줄이기는 처음 방문 시 기본값으로 적용하고 이후에는 사이트에서 선택한 설정이 우선한다.
- `npm run build` 성공. 브라우저에서 공전 적용, 효과 끄기와 새로고침 후 설정 유지 및 신규 카드 표시를 확인했다. OS 설정을 바꾼 실기기 검증은 하지 않았다.
