## 2. 담당 분야별 쓸 곳

- **과자·장난감·패션·가전·게임 (아이템 목록)**: 위키데이터(출시일 있는 항목) → 위키백과 → 나무위키(비영리일 때만). 공식 통계 보강은 KOSIS(물가·보급률).
- **유행어**: 정리된 공공 데이터셋은 찾지 못했다 [미확인]. 국립국어원 신어 조사 자료가 후보지만 이번에 확인 안 함 [미확인]. 2016년 이후는 데이터랩으로 시기 검증.
- **사건·뉴스**: 위키백과 연도 문서(월·일) + 빅카인즈(1990~, 웹) + 뉴스 라이브러리(~1999, 링크만).
- **연표**: 위키백과 연도별 문서가 가장 손쉽고, 국가기록원·국사편찬위원회로 교차 확인.

## 3. 수집 추천 순위

### A. API로 바로 가능
1. **위키데이터** — SPARQL로 연·월별 사건·제품 출시 일괄 추출, CC0.
2. **위키백과 한국어** — MediaWiki API·덤프, CC BY-SA 4.0(출처 표기 필요).
3. **KOSIS OpenAPI** — 물가·보급률 시계열, 분당 200회.
4. **네이버 데이터랩 API** — 2016년 이후만.
5. **공공데이터포털 경유 기관 데이터**(국가기록원 등) — 데이터셋별 명세 확인 필요.

### B. 파싱·수작업 필요
6. **빅카인즈** — 웹 검색 + 엑셀 다운로드. API는 공모 선정 시만.
7. **한국민속대백과사전 / 한국사데이터베이스 / e뮤지엄** — API 여부 [미확인], 웹 열람 후 선별.
8. **한국콘텐츠진흥원 게임백서** — PDF에서 표 추출.

### C. 사용 어려움
9. **나무위키** — NC 라이선스(상업 불가), robots.txt 기본 차단, 운영사 해외.
10. **네이버 뉴스 라이브러리** — API 없음, 기사 저작권은 언론사. 날짜별 링크 연결만.
