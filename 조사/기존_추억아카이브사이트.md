## 데이터로 바로 활용 가능한 곳 TOP

이용 조건을 직접 확인한 곳이 적어서 "바로 사용 가능"이라고 확정한 곳은 없다. 아래는 확인할 가치가 높은 순서다.

1. **공공데이터포털(data.go.kr) + 문화포털 오픈API** — 인증키 방식 공식 API 창구(문화포털 안내 페이지로 확인). 데이터셋별 공공누리 유형을 확인하면 가장 안전하다. 연도별 물가·통계 축 데이터 후보.
2. **국립민속박물관 한국민속대백과사전·소장품** — 물건 설명의 공신력 있는 출처. API 존재와 이용허락 범위는 [미확인]이므로 data.go.kr에서 "국립민속박물관"으로 직접 검색해 확인해야 한다.
3. **Internet Archive / Wayback** — 공개 API가 있는 것으로 알려짐 [미확인]. 링크로 연결하는 정도는 부담이 적다.
4. **광고정보센터·Retro Junk** — robots.txt로 AI·자동 수집을 명시적으로 막았다 [확인]. **수집하지 않고 링크·출처 표기만** 한다.
5. 음악 차트(멜론·가요톱10·Billboard 등) — 재배포 조건 [미확인]. 곡명·가수 같은 사실 정보만 직접 정리하고 음원·가사·앨범 이미지는 쓰지 않는 쪽이 안전하다 [제안].

## 벤치마킹할 기능 TOP

1. **연도 한 페이지에 물건·노래·물가·뉴스를 묶기** (The People History 구조, [미확인]) — 우리는 여기에 월 단위를 더한다.
2. **사용자가 "그해 내 추억" 사진·글을 연도 태그와 함께 올리기** (보배드림 게시판에서 연도를 제목에 적는 관행) — 사람들은 이미 이렇게 하고 있으니 연도 입력란을 정식으로 만들어 주면 된다.
3. **등록 기준 규칙** (퀘이사존 "출시 7년 이상만") — 예: "최소 5년 지난 것만 추억 등록" 같은 간단한 규칙으로 품질 유지 [제안].
4. **세대 필터** (브런치 에세이에서 본 "세대마다 기억하는 물건이 다르다") — 출생연도를 넣으면 "내가 10살 때" 화면으로 바로 이동 [제안].
5. **지도 + 연도 회상** (WhatWasThere, [미확인]) — 동네·학교 추억. 후순위.
6. **카톡·인스타·블로그 공유 카드** — 조사한 공공 아카이브에는 회상·공유 UX가 보이지 않았다 [미확인]. 연도 카드 이미지를 한 번에 공유하는 기능이 차별점이 된다.
7. **공식 출처 링크 표기** — 공공 아카이브 자료는 직접 싣기보다 출처 링크로 신뢰도를 빌려 온다.
