## 0. 먼저 알아 둘 것 (앞선 조사 정정 포함)

1. **`데이터출처_생활문화뉴스.md`의 국가기록원 데이터셋 번호는 틀렸다.** 15148324, 15148327을 직접 열어 보니 둘 다 **한국보훈복지의료공단**의 기록물철 통계 CSV다(사진 없음). https://www.data.go.kr/data/15148324/fileData.do , https://www.data.go.kr/data/15148327/fileData.do . 국가기록원 사진 API는 이번 검색으로도 찾지 못했다 [미확인].
2. **같은 서울 사진인데 공공누리 표시가 문서마다 다르다.** 서울역사박물관 보도(2023)는 "1유형", 서울시 보도(2016)의 페이지 하단 마크는 4유형이다. 보도 페이지 하단 마크는 그 기사 자체의 표시일 수 있다. 사진 한 장 한 장의 상세 페이지 표시를 직접 보고 확정해야 한다. 4유형이면 광고 사이트에는 쓸 수 없다.
3. **공공누리가 2026-01-28 개정되어 제0유형(조건 없는 자유이용)과 AI 학습용 유형이 신설됐다는 검색 요약이 있다** [검색: 한국문화정보원 계열 자료, 원문 미확인]. 새로 수집할 때 0·1유형만 골라 담는 기준으로 쓰기 좋다.
4. **Flickr API는 광고 수익 사이트를 "상업적"으로 분류한다** (아래 표 12).

## 2. 이 시기(1980~1999) 이미지가 빈약한 이유 [해석]

- 공공 아카이브의 "저작권 만료·공공누리 1유형" 자료는 **1960년대 이전**에 몰려 있다 (국가기록원 만료분 1962년 이전, 국립중앙도서관 신문 1960년대까지, 공유마당 만료저작물).
- 1980~99는 **정부·지자체가 직접 촬영한 사진**(서울시정사진, 대통령기록사진, 올림픽 기록)만 합법적으로 모을 수 있고, **상업 제품·광고·포스터·음반 커버는 권리자가 따로 있다**.
- 따라서 이 시기의 "추억 물건·노래·트렌드" 이미지는 ① 공공 사진(시대 분위기), ② 박물관 소장품(물건 실물), ③ KMDb 포스터(링크·썸네일), ④ 사용자 업로드가 현실적이다.

## 3. 수집 추천 순서

### A. 바로 가능 (공식 API·다운로드 + 조건이 명확)
1. **Wikimedia Commons** — API 키 없이 사용. `deepcategory` 검색으로 후보 추출 → 파일별 `extmetadata`로 라이선스 필터(CC0·PD·CC BY·BY-SA만, NC·ND 제외). 저작자 표시를 DB 필드로 저장. 한국 공공기관이 올린 `KOGL Type 1` 사진(14,410)이 1980년대 정부 사진 비중이 높다 [확인].
2. **KMDb Open API** — 영화 메타데이터·연도 필터는 문제없음. 단 **포스터·스틸 이미지는 이용 조건 문의 후** 쓴다 [추정 근거: 데이터셋에 이미지 없음, API 본문에 이미지 권리 문구 없음]. 문의 전에는 `posterUrl` 링크·썸네일 표시까지만 검토.

### B. 조건 확인 후 가능
3. **서울역사아카이브·서울기록원 시정사진** — 1유형인지 4유형인지 불일치. **서울역사박물관(서울기록원)에 "광고 사이트 상업 이용·리사이즈 가능 여부"를 서면 문의**해서 확인되면 1980년대 사진 수백~수천 장 확보 가능. 확인 전에는 4유형으로 보고 사용하지 않는다.
4. **국립민속박물관 데이터셋** — data.go.kr 파일데이터 8건 중 소장유물·민속아카이브의 컬럼에 이미지 URL이 있는지, 공공누리 유형이 무엇인지 파일을 열어 확인. 연대 정보가 있으면 1980~90년대 생활용품 사진 확보 가능.
5. **e영상역사관 사진관·KTV 나누리** — 2025-07 전면 개방 취지에 맞춰 **사진 조건을 KTV/문체부에 문의**. 대통령기록사진·국가기록사진은 1980~90년대 정부 행사 사진이 많을 것으로 기대 [추정].
6. **공유마당 기증·CC 이미지** — 1980~99 광고·사물 이미지가 있는지 목록에서 직접 걸러 봐야 한다.

### C. 링크·출처 표기만 (이미지 직접 게재 금지)
7. 광고정보센터·한국광고박물관 디지털 아카이브(약 4만 5천 점), 네이버 뉴스라이브러리, KBS·MBC·EBS 아카이브, 제조사 역사관 — 각 사이트 약관·robots.txt 상 수집 불가 또는 미확인. 연도별 큐레이션 링크로만 연결.
8. **Flickr·국가기록원 사진** — Flickr는 광고 사이트에 별도 승인 필요, 국가기록원은 1980~99 사진의 공공누리 적용을 확인하지 못함. 승인·확인 전 제외.
