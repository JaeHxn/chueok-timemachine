## 4. 공백 (못 찾은 것)

- 1950~1980년대 가요 순위의 **공식** 데이터: 찾지 못함. 신문 아카이브(네이버 뉴스 라이브러리 등) 검토 필요 [미확인].
- 2003년 이전 영화 흥행 공식 집계: KOBIS 이전은 서울 개봉관 기준 자료로 알려져 있으나 출처 [미확인].
- 1990년대 이전 시청률: 공개 출처 찾지 못함.
- 지상파 3사 과거 편성표 공공 API: 찾지 못함.

## 수집 추천 순위

1. **바로 API로 받을 수 있는 것**
   - KOBIS 오픈API (일/주간 박스오피스, 영화 목록·상세) — 키 즉시 발급. 단 한도·약관 확인 먼저.
   - 위키데이터 SPARQL — 키 불필요, CC0. 연도별 영화·노래·드라마 메타데이터 뼈대.
   - KMDb 오픈API — 승인 1~2일. 고전 영화·포스터 보강용.
2. **파싱 필요한 것**
   - 위키백과 연도별 1위 목록·드라마 목록 (MediaWiki API/덤프, CC BY-SA 출처 표기).
   - 닐슨코리아 공개 시청률 페이지 (일/주간 TOP20, 약관 미확인이라 허가 문의 권장).
   - 써클차트 웹페이지 (robots.txt 없음, 약관 확인 후. 제휴 문의가 안전).
3. **사용 어려운 것**
   - 멜론 차트 — robots.txt가 일반 크롤러 전면 차단. 공식 API 없음.
   - 1990년대 이전 가요 순위·시청률 — 공식 출처 없음. 신문 아카이브 수작업 수준.
   - 지상파 방송사 과거 편성표 — 공공 API 없음.
