# 이미지 수집처 조사 (2000~2026) — 합법 수집·표시 가능 여부

> 조사일: 2026-11-17 · 담당: 2000~2026년 이미지(사진·광고·포스터·제품·앨범·방송·밈·스크린샷)
> 표기: **[확인]** = 이번 조사에서 해당 URL/API를 직접 열어 확인 / **[검색]** = 웹 검색 요약으로만 확인(원문 미열람) / **[미확인]** = 확인 못 함 / **[일반지식]** = 근거 없이 기존 지식(재확인 필수).
> 이 사이트는 **구글 애드센스 광고가 붙는 영리 사이트**이므로 "상업적 이용 가능 + 출처표시만" 조건만 자동 수집 대상으로 본다. 법률 판단이 아니며 공개 전 전문가 검토를 권한다.
> 한계: 조사 후반에 도구 사용 한도에 걸려 일부(삼성 뉴스룸 이용약관, 관광공모전 사진 API 상세, CDX 문서, X oEmbed, 국립민속박물관 접속)는 확인하지 못했다. 해당 칸에 [미확인] 표시.
> 이미 정리된 항목(공공누리 유형표, 서울역사아카이브·국립민속박물관·e뮤지엄 개요 등)은 `데이터출처_이미지권리.md`를 참조하고, 여기서는 **새로 직접 열어 확인한 값**만 적었다.

## 0. 핵심 결론 (먼저 읽기)

1. **2000년 이후 이미지는 저작권 보호기간이 끝난 것이 사실상 없다.** 한국 저작권 보호기간은 저작자 사후 70년, 업무상저작물·영상저작물은 공표 후 70년이고, 1976년 이전 사진만 퍼블릭도메인이다 (Wikimedia Commons, Copyright rules by territory/South Korea — https://commons.wikimedia.org/wiki/Commons:Copyright_rules_by_territory/South_Korea [확인]). 그러므로 공유마당의 "만료저작물" API로는 2000년대 이미지를 얻을 수 없다.
2. 2000~2026 이미지를 합법적으로 자동 수집·표시할 수 있는 통로는 **(a) Wikimedia Commons의 자유 라이선스 파일, (b) Korea.net(문체부 해외문화홍보원) Flickr·Commons 사진, (c) 공공누리 1유형이 명시된 정부·공공기관 사진(한국관광공사 TourAPI, 서울역사아카이브 등), (d) 사용자 업로드(약관 보증 필요)** 정도다. 규모는 크지 않다.
3. **앨범 커버·영화 포스터·광고·방송 화면·밈·제품 사진은 권리자가 따로 있어 수집·재게시 대상이 아니다.** 메타데이터(곡명·개봉일 등)만 저장하고 이미지는 **공식 임베드(유튜브 등) 또는 외부 링크**로 푼다 (§3, §4).
4. 광고정보센터·Retro Junk처럼 robots.txt로 명시 차단한 곳은 이미 `기존_추억아카이브사이트.md`에서 수집 제외로 판단했다.

## 3. 유튜브 등 공식 임베드·링크로 푸는 부분

### 3-1. YouTube
- **허용**: 약관이 "내장 가능한 YouTube 플레이어를 통해 동영상을 표시"하는 것을 허용 [확인: https://www.youtube.com/t/terms].
- **금지**: 다운로드·캐시·저장은 YouTube 서면 승인 필요, 오디오·비디오 분리 금지, 플레이어 변경·가림 금지, 임베드를 iframe으로 감싸 출처를 숨기는 행위 금지 [확인: Developer Policies https://developers.google.com/youtube/terms/developer-policies].
- **API로 받은 메타데이터**는 대부분 **30일 내 삭제·갱신** 필요 [확인]. 썸네일은 정책에 별도 조항이 없어 같은 저장 규칙이 적용된다고 보는 것이 안전 → **썸네일 이미지를 우리 서버에 영구 저장하지 않는다.** 영상 ID만 저장하고 임베드 플레이어(썸네일은 플레이어가 표시)로 보여 준다.
- **광고**: YouTube 콘텐츠만 있는 페이지에서는 광고 판매 금지, **비YouTube 콘텐츠가 충분한 독립 가치를 가질 때만 광고 가능**, 플레이어 위·안에 광고 판매는 승인 필요 [확인: Developer Policies, ToS]. → 임베드 옆에 우리가 쓴 연·월 설명·곡 정보를 반드시 두고, 영상만 나열하는 페이지는 만들지 않는다.
- **어린이용 영상**: 임베드된 각 영상의 Made for Kids 여부를 확인(추적 끄기·COPPA/GDPR) [확인].
- **쿼터**: 기본 하루 10,000 유닛, `videos.list` 1유닛. `search.list`는 별도 버킷으로 **하루 100회**라고 문서에 적혀 있음 [확인: https://developers.google.com/youtube/v3/determine_quota_cost] — 수치가 이전 알려진 값(100유닛)과 달라 호출 전 재확인.
- **공식 채널 후보**: 한국영상자료원 고전영화 채널(youtube.com/koreanfilm, 1930년대~1990년대 중심 200편 이상 [검색: https://blog.youtube/news-and-events/70-korean-cinema-classics-come-to/]) — 2000년 이후 영화는 해당 안 됨. 영상별 임베드 허용 여부는 [미확인].
- 방송사·음반사 공식 채널 영상의 임베드 허용(영상별 "퍼가기" 설정)은 영상마다 다르므로 `status.embeddable`을 API로 확인 [일반지식, 재확인].

### 3-2. SNS 공식 임베드
- **Instagram oEmbed**: 공개 게시물·릴스·프로필 임베드 가능, 스토리·비공개·임베드 비활성 계정 불가, **시간당 1,000회**, 임베드 외 용도(분석 등) 금지 [확인: https://developers.facebook.com/docs/instagram-platform/oembed]. 샘플 요청에 토큰이 없으나 인증 요건 명시 없음 → 앱 심사·토큰 필요 여부 [미확인].

- **Naver 블로그·카페 게시물**: 임베드 공식 정책 [미확인](조사 안 함).

## 4. 수집 추천 순서

### ① 바로 가능 (키 발급·API만으로, 영리 가능 조건 확인됨)
1. **Wikimedia Commons API** — `Category:YYYY photographs of South Korea` 및 `Category:YYYY in South Korea`(월별 하위 포함, 예: January 2005 in South Korea [확인])를 순회, `extmetadata`로 CC BY·BY-SA·CC0·PD만 통과. 규칙: 설명적 UA, **직렬 요청**, 초당 몇 건 이하, 대량이면 덤프.
2. **Commons의 Korea.net Flickr 사진 15,269건** — 같은 API, 파일별 라이선스 필터(CC BY-SA 2.0 위주, 제한 문구 있는 파일은 제외).
3. **한국관광공사 TourAPI 사진** — 인증키 발급, 공공누리 1·3유형 확인, 3유형은 원본 유지. 장소 카드용.
4. **KMDb API의 메타데이터** — 제목·개봉일·감독만. 이미지 URL은 저장하지 않고 링크.

### ② 조건 확인 후 (문의·승인·건별 표시 확인 필요)
5. **Flickr CC API** — 영리 사이트이므로 **상업용 API 키 신청이 선행**. 승인 시 `license=4,5,9,7,10` + 촬영일 필터. 사진 30장/페이지 제한 준수.
6. **서울역사아카이브(1유형)** — sitemap으로 목록 확인, 2000년 이후 자료 존재량 파악 후 수동 선별. robots는 `/archive/` 허용.
7. **e영상역사관 사진관·정책브리핑** — 공공누리 표시 건만, 사진은 문체부 콘텐츠기획과 협의 후.
8. **KMDb 포스터·스틸** — 한국영상자료원에 "광고 사이트 게재 가능 여부" 서면 문의.
9. **공유마당 CCL·공공누리 1유형** — 건별 확인, 대량 수집 금지(robots가 파일 다운로드 경로 차단).
10. **Unsplash/Pexels/Pixabay** — 한국 옛 사진이 부족할 가능성이 커 후순위. 쓴다면 각 약관(핫링크·캐시·표기) 준수.

### ③ 링크·임베드만 가능 (수집·게재 금지)
11. 유튜브 공식 임베드(곡·CF·예고편), Instagram oEmbed, Wayback 스냅샷 링크.
12. 광고정보센터(robots 금지), 서울기록원 사진(4유형), 국립무형유산원 사진(4유형), 앨범 커버·영화 포스터·방송 화면·밈·제품 광고 이미지.
