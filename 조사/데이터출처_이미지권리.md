## 2. 짧은 확인 사항

### (a) 앨범 커버·제품 사진·영화 포스터 썸네일 위험
- 앨범 커버·포스터·제품 광고사진은 대부분 사진·미술 저작물로 보호된다. 공공저작물이 아니다.
- **저작권법 제35조의5(공정한 이용)** 4요소: 이용 목적·성격 / 저작물 종류·용도 / 이용 비중·중요성 / 시장·가치에 미치는 영향. 법조문 https://www.law.go.kr/법령/저작권법
- 썸네일 판례: **대법원 2006. 2. 9. 선고 2005도7793** — 검색엔진 썸네일을 정당한 인용으로 본 사건. 현행 제35조의5(2011년 도입) 이전 판결이라 그대로 적용된다고 볼 수 없다. 현행 조문 아래 썸네일 직접 판례는 [미확인]. (출처: 한국저작권위원회 상담사례 https://www.copyright.or.kr/business/counsel/auto-advice-service/practice/detail.do?counselSeq=3578 , 법률신문 https://www.lawtimes.co.kr/opinion/209002)
- 위 판결은 "원본으로 연결하는 검색 서비스" 맥락이었다. 아카이브가 이미지를 자체 콘텐츠로 상시 노출하면 사정이 다를 수 있다 [추정 아님: 판단 유보]. 확정 정책인 ③(출처 링크+설명, 이미지 미게재)이 가장 보수적이다.
- 상표(로고)·퍼블리시티(연예인 얼굴)도 별도 쟁점 [미확인 범위].

### (b) 사용자 업로드 약관 일반 항목
- 업로더 보증: 본인 촬영 또는 권리 보유, 제3자 권리 침해 없음.
- 이용허락: 서비스 내 게시·복제·리사이즈에 대한 비독점 이용허락(범위·기간·철회 방법 명시).
- 초상권: 식별 가능한 타인 등장 시 동의 확보 책임, 당사자 삭제 요청 절차. 초상권은 성문 조항이 아니라 판례로 인정되는 권리 [일반지식].
- 개인정보: 얼굴·차량번호 등은 개인정보보호법 대상 가능 → 처리방침 반영(https://www.law.go.kr/법령/개인정보보호법).
- 신고·삭제: 저작권법 제103조(복제·전송 중단 요청) 절차 — 온라인서비스제공자 책임 제한(제102조) 요건 [일반지식, 조문 확인]. 사생활·명예 침해는 정보통신망법 제44조의2(임시조치) (https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률).
- 반복 침해자 계정 조치, 메타데이터(EXIF 위치) 제거 고지.

### (c) AI 생성 이미지 표시
- **인공지능 발전과 신뢰 기반 조성 등에 관한 기본법(AI 기본법)** 및 시행령 2026-01-22 시행 [확인: 뉴시스 https://www.newsis.com/view/NISX20260121_0003484769 , 신앤김 뉴스레터 https://shinkim.com/kor/media/newsletter/pdf/3114].
- 표시 의무는 **AI 사업자**(서비스 제공자) 대상, 창작도구를 쓰는 이용자는 제외된다는 보도. 방식은 가시적 표시 또는 워터마크·메타데이터. 과태료 최대 3,000만 원, 과기정통부 1년 이상 계도기간 운영 방침(보도).
- 이 사이트가 AI 이미지를 직접 생성·제공하면 "사업자"에 해당하는지 [미확인] — 법제처 조문(제31조 추정, 조문 번호 [미확인])과 과기정통부 가이드라인 원문 확인 필요. 확정 정책인 ②(배지 표시)는 방향이 맞다. 실존 인물 재현은 딥페이크 쟁점이므로 피한다.

## 3. 바로 쓸 수 있는 이미지 출처 추천 순위

1. **서울역사아카이브** — 공공누리 1유형(상업·변경 가능), 1950~ 서울 생활사. API는 없을 가능성 → 수동 큐레이션.
2. **국립민속박물관 아카이브** — 1유형 언급, 생활사 사진. 건별 표시 확인.
3. **Wikimedia Commons** — API 키 없이 자동 수집 가능, 파일별 라이선스 메타데이터 제공. PD 판정 오류 주의, BY-SA 조건 준수.
4. **공유마당** — CC·만료 저작물, 건별 조건 명확. API 확인 필요.
5. **e영상역사관(KTV)** — 1950~ 대한뉴스 등 시대 자료 최다 기대. 사진 이용 조건 확인 후 승격.
6. **Flickr CC API** — CC BY/CC0/PD만 필터(NC 제외). 한국 근현대 자료는 적음.
7. **국가기록원·e뮤지엄** — 이용조건 건별 상이·대중문화 비중 낮음 → 보조.

공통: 모든 이미지에 출처·라이선스·원본 URL을 DB 필드로 저장하고 화면에 표시한다.
