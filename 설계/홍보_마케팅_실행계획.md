# 🚀 추억 타임머신 — 실전 홍보·마케팅 실행 계획서

> **서비스 URL**: https://chueok-timemachine.pages.dev/  
> **목표**: 초기 시드 유입 확보 → 카톡·인스타 자발적 바이럴(공유율 30%+) → 검색(SEO/AEO/GEO) 상시 유입 구축

## 1. 핵심 바이럴 무기 3가지 (Hook)

| 무기 | 타깃 세대 | 핵심 심리 | 랜딩 경로 |
| :--- | :--- | :--- | :--- |
| **① 나의 황금기 테스트** | 20~30대 (Z·밀레니얼) | "내 9:16 인스타 인증서 자랑하고 싶다" | 홈 배너 → `황금기 테스트` 모달 |
| **② 카톡 단톡방 딥링크** | 40~60대 (X·베이비부머) | "야 너 이거 기억나냐? ㅋㅋㅋ" 동창회 수다 | `/#/1988`, `/#/1998` 등 카드 딥링크 |
| **③ 왕 큰 글씨 효도 모드** | 부모님 세대 & 자녀 | "부모님 카톡에 보내드리면 좋아하시겠다" | 상단 `[👓 큰 글씨 모드]` |

## 2. 단계별 실전 살포(배포) 로드맵

### Phase 1: 시드 유입 점화 (1~3일 차)
1. **지인·가족 카톡방 1차 투하**
   - [SNS_바이럴_전파_가이드라인.md](./SNS_바이럴_전파_가이드라인.md)의 카톡 템플릿을 그대로 복사해 가족방·동창회방·동기방 5곳에 공유.
   - 본인의 `황금기 테스트 인증서` 이미지를 함께 올리면 클릭률(CTR)이 2배 이상 상승함.
2. **커뮤니티 시드 포스팅 (하루 2~3곳)**
   - **네이버 블로그**: `"1950~2026 추억 타임머신 & 나의 황금기 테스트 후기"` 제목으로 포스팅 (본문 중간에 링크, 하단에 태그 10개).
   - **X (트위터)**: `"출생연도만 치면 내 학창시절 유행어·노래·과자 다 뜨는 사이트 ㄷㄷ"` 2줄 훅 + 인증서 캡처 이미지 업로드.
   - **커뮤니티 (블라인드·에브리타임·맘카페·7080 카페)**: 광고 티를 빼고 `"심심해서 해봤는데 내 초등학생 때 문방구 보물 정확히 맞추네 ㅋㅋ"` 식의 후기형 공유.

### Phase 2: 숏폼 & 릴스 확산 (1~2주 차)
1. **인스타그램 릴스 / 유튜브 쇼츠 / 틱톡 (주 3회)**
   - **포맷**: 15초 퀴즈형 (`"1990년대생이면 무조건 소름 돋는 3가지"`, `"2002년생이 기억하는 그 시절"`).
   - **CTA**: `"내 황금기 테스트 해보기 👉 프로필 링크 / 댓글 고정"`.
2. **유튜브/인스타 댓글 참여 유도**
   - `"여러분은 몇 년생이신가요? 황금기 테스트 결과 댓글로 남겨주세요!"`로 알고리즘 노출 극대화.

### Phase 3: 검색(SEO)·AI(AEO/GEO) 상시 유입 안착 (3~4주 차)
1. **검색엔진 등록 (최초 1회 필수)**
   - **구글 서치 콘솔**: `https://chueok-timemachine.pages.dev/sitemap.xml` 제출.
   - **네이버 서치어드바이저**: 사이트 소유 확인 후 `sitemap.xml` 제출 및 웹페이지 수집 요청.
2. **AEO / GEO 유입 점검**
   - ChatGPT, Perplexity, 네이버 Cue 등에서 `"한국 연도별 추억 사이트 추천"`, `"1990년대 추억 아카이브"` 검색 시 노출 여부 확인.

## 3. 운영 시 주의사항 (스팸 차단 방지)
- 동일 커뮤니티에 하루 2회 이상 도배 금지 (자연스러운 후기 톤 유지).
- 링크만 달랑 올리지 말고 **본인 황금기 테스트 결과 캡처 1장 + 소감 2줄**을 반드시 함께 첨부할 것.
